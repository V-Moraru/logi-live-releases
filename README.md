# Logi Live Bridge

The Mac half of Logi Live, an iPad mixer for Logic Pro. The bridge lives in the menu bar, talks to Logic as a Mackie Control surface and connects to the iPad app over your local network.

## Download

**[Download Logi-Live-Bridge.dmg](https://github.com/V-Moraru/logi-live-releases/releases/latest/download/Logi-Live-Bridge.dmg)**: always the newest version. Earlier versions are on the [Releases](https://github.com/V-Moraru/logi-live-releases/releases) page.

Needs macOS 14 or later and Logic Pro.

## Install

1. Open the DMG and drag **Logi Live Bridge** onto **Applications**.
2. Open Logi Live Bridge from Applications.
3. Follow the setup guide. It explains every permission, opens the right System Settings page in one click and shows the code that pairs the iPad.

The iPad app isn't publicly available yet.
